TickTracker 4.1.4, packaged as a module for Sonaria Software Launcher. The launcher downloads this file itself and checks it against a SHA-256 built into the launcher, so there is nothing to install by hand.

New since 4.1.3: the health bar is read correctly with Windows HDR switched on. With HDR on, screen captures come back much brighter and the bar's green is pinned at its maximum, so TickTracker could not recognise the bar and the badge only showed the heart. Nothing changes with HDR off. This is 4.1.3 plus that fix; it does not include 4.2.0's badge hiding.
