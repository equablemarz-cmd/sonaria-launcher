TickTracker 4.1.0, packaged as a module for Sonaria Software Launcher. The launcher downloads this file itself and checks it against a SHA-256 built into the launcher, so there is nothing to install by hand.

New since 4.0.1: a combat alert. If a fight starts while you are tabbed out of Roblox, the badge switches to a pulsing alert until you click back into the game, and a connected controller buzzes. To see the game while it is behind another window, TickTracker asks Windows for a picture of the Roblox window, the way OBS window capture does. It still never reads the game's memory or presses anything for you. Right-click the badge to switch the alert off or test it.
