Damage Counter 1.0.3, packaged as a module for Sonaria Software Launcher. The launcher downloads this file itself and checks it against a SHA-256 built into the launcher, so there is nothing to install by hand.

New since 1.0.2: the panel looks 3D, like TickTracker's badge. It now has a stone edge underneath (shading from light to dark), a bright lip where the face turns down into it, and its lighter rim gets thicker towards the bottom. Reading and counting are unchanged.
