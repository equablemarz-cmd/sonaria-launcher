# Sonaria Software Launcher

> [!IMPORTANT]
> This is an early work in progress. There are no releases yet.
> It is **not** Bloxstrap and is not affiliated with or endorsed by the Bloxstrap developers or by Roblox.
> The only official place to download it will be this GitHub repository.

A PvP-focused Roblox launcher for Creatures of Sonaria, by Sonaria Software.

It is a fork of [Bloxstrap](https://github.com/bloxstraplabs/bloxstrap) by pizzaboxer and contributors, used under the MIT licence (see [LICENSE](LICENSE)). All of Bloxstrap's launcher features are kept; the Sonaria additions are being built on top:

- a one-click Launch CoS button and detection of when you are in Creatures of Sonaria
- TickTracker (the natural heal tick timer) built in, starting and stopping with CoS
- PvP-minded presets, using only settings Roblox officially allows
- updates that ask first and are verified before they are applied

## Is it safe?

Like Bloxstrap, the launcher only starts Roblox and works with Roblox's own local files (settings, logs, mod folder). It never reads, writes or injects into the Roblox game process. TickTracker only looks at the screen.
